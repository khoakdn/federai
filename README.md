# FederAI – Federated Learning Educational Website

Welcome to **FederAI** – an educational website that explains **Federated Learning (FL)** in a clear and accessible way.  
This platform is part of the **Art-IE** project and is funded by **Interreg** and the **European Union**.

🔗 **Live Site**: [https://federai.netlify.app/](https://federai.netlify.app/)  
📽️ **Video Overview**: Included in the homepage

---

## 🌟 Features

- ✨ Simple explanation of Federated Learning (text + diagrams)
- 🎬 Embedded educational video
- 🧠 Researcher and student work (posters, white papers, results)
- 📄 Publications with month-based filtering
- 🌍 EU and Interreg logos in compliance with branding guidelines
- 📱 Fully responsive and accessible design

---

## 🧪 Development & Deployment

1. Clone the repo:
   ```bash
   git clone https://github.com/khoakdn/federai.git
   cd federai
   ```

2. Open `index.html` in your browser or use Live Server if using VS Code.

3. Deployment is handled via [Netlify](https://www.netlify.com/).
